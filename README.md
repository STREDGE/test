# Сжатие видео (Android)

Приложение сжимает видео до заданного размера (по умолчанию 30 МБ): перекодирует
видеодорожку аппаратным кодеком HEVC (H.265) или H.264, звук копирует без изменений.

- Готовый APK: `apk/VideoCompressor.apk` (Android 10 и новее).
- Сборка: `./build.sh` — нужны `aapt`, `zipalign`, `apksigner`, `dalvik-exchange` из apt и JDK.
- `signing.keystore` — ключ подписи для личной установки, пароль записан в `build.sh`.
  Для публикации в магазине замените его своим.
